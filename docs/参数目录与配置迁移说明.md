## 设置入口及生效时间

SettingFrm → SoftwareConfig → 功能路径。原“参数目录”改为“全局参数目录”；页面下部增加“换型参数目录”“软件版本文件”“抛料统计文件”。保存到当前选定的 CPrimConfig.json，重启后使用新路径。

| JSON 字段 | 默认或旧配置回退 | 文件位置 |
|---|---|---|
| GlobalParamDirPath | 旧 DynamicParamDirPath；旧值为空时使用 D:\Config\CPrimConfig\DynamicParam | 目录内的 CommonParam.para |
| ProductParamDirPath | 旧 DynamicParamDirPath\ProductCfg | 直接存放 AudioAirPods.para 和 AudioAirPods_模式名.para |
| LeadVersionFilePath | D:\Config\IniConfig\Lead.ini | 软件版本标识 |

版本及统计路径由 MainForm 启动时传入 ProxyTools.RuntimeConfigPaths；版本读取同时刷新 UIGlobal.Version 缓存。TossingControl 第一次访问时固定统计文件路径，后续读取与写入均使用同一文件。

## 模式参数行为

- 全局参数页已移除模式参数编辑区，不再读取或生成 CommonParam_模式名.para。CommonParam 中的运行模式状态及工站模式通知保留。
- 换型参数页右侧新增模式参数区。通过参数右键菜单加入或移除模式项，只接受当前产品已有且类型一致的参数。
- 更新后的行为：启动/换产品时读取主文件并应用模式一次；同产品切模式以当前 UI 缓存为基础。加载不再写回产品文件。显式赋值同步运行内存与 UI，普通保存不重新覆盖未改动的模式值；仅人工修改的模式项在保存时应用。
- **按用户确认沿用旧行为：空模式不恢复旧值，移除覆盖项也不会恢复覆盖前的值。**
- 换产品时重新加载该产品与当前模式；产品复制包含各个运行模式文件，源模式缺失时目标使用空参数集。界面刷新/语言切换不再隐式保存。
- 缺少模式文件时在内存使用空覆盖表，不因读取创建文件；损坏 XML、重复项、非当前产品项及类型不符均报错，不将其作为成功的模式切换。主参数文件需预先提供，不在启动时自动生成。
- 修正 CurrentProduct 的递归通知；反序列化不触发对运行实例的换型，显式静默换型不再发出额外通知。
