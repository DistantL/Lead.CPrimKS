## 框架行为

- 工位开关的 HIVE 编辑保护从全局页面移至换型页面，用四个固定索引名称识别，不依赖显示名称。
- DT 时允许编辑，非 DT 只读；页面权限/运行禁用继续有效。模式覆盖项在主表保持只读，在模式表也受 HIVE 限制。
- 初始化、模式/产品切换、保存、转移刷新及 HIVE 通知重新应用保护，关闭窗体解除 HIVE 订阅；后台通知在 UI 线程读取最新状态。
- 对 96 个迁移索引审查框架直接参数调用，没有发现需要重定向的硬编码读写；关联代码变更为上述工位编辑保护。同名的普通字段、日志及未迁移索引不作替换。
- 上一轮运行模式迁移不变，不提供旧全局参数调用别名。

## 直接保存

所有通过参数界面进行的普通保存和双向转移不再生成 .save/.transfer 备份或临时文件，不执行失败回滚，不清理已有历史备份。

所有文档先校验并在内存序列化，再核对文件快照后直接覆盖。转移先写目标，再写源；全部成功后刷新运行数据和页面、清空待转移清单。

写入失败报告当前失败文件和此前已写文件。转移保存或刷新失败后锁定会话并保留清单，要求检查文件、关闭窗口重新加载；不重试、不假称恢复。普通保存失败不更新运行集合或显示成功。

这是明确选择的非原子保存：中断、断电、磁盘写入失败可能留下截断文件或部分更新，不能自动恢复。
